#+TITLE: =My dotfiles=

* Welcome

In this repository, I gather my system configurations that allow me to have
a consistent computing experience over multiple Linux machines.

It configures three main tools: [[https://www.gnu.org/software/emacs/][GNU Emacs]], [[https://zsh.sourceforge.io/][ZSH]] and the [[http://docs.qtile.org/en/stable/][Qtile]] window
manager.

I use [[https://www.gnu.org/software/stow/][GNU Stow]] to install my configuration files on my Linux
distributions. Everything can be rolled out by calling the main
configure script of the repository

#+BEGIN_SRC shell
  ./configure
#+END_SRC
