* System Configuration

In this repository, I gather my system configurations that allow me to have
a consistent computing experience over multiple Linux machines.

It configures three main tools: [[https://www.gnu.org/software/emacs/][GNU Emacs]], [[https://zsh.sourceforge.io/][ZSH]], and [[http://docs.qtile.org/en/stable/][Qtile]].

I use [[https://www.gnu.org/software/stow/][GNU Stow]] to install my configuration files on my Linux
distributions. Everything can be rolled out by calling the main
configure script of the repository


#+begin_src shell
./configure -i
#+end_src

** Fresh Device Bootstrap

On a brand-new device, download the =bootstrap= script and run it to pull the
GnuPG keys, password store, and dotfiles from =pauline=. Both SSH key and
username/password authentication are supported; when no key is installed yet,
SSH prompts for =pauline='s password exactly once — the connection is reused
across all three rsync transfers via SSH ControlMaster multiplexing.

#+begin_src shell
curl -O https://raw.githubusercontent.com/fabianfranzelin/dotfiles/nightly/bootstrap
chmod +x bootstrap
./bootstrap              # or: ./bootstrap blackview
#+end_src

If =pauline= isn't resolvable from your current network, the script tries the
following hosts in order: =pauline=, =192.168.178.48=, then
=franzelin.dyndns.org=. You can override this with an explicit remote as the
second argument, or via the =REMOTE= / =REMOTE_HOSTS= environment variables:

#+begin_src shell
./bootstrap blackview frf2lr@192.168.178.20
REMOTE=frf2lr@franzelin.dyndns.org ./bootstrap blackview
REMOTE_HOSTS="pauline 10.0.0.5 other.example.org" ./bootstrap blackview
#+end_src

Then run =./configure -i= from the freshly synced dotfiles.

** Overlay Directories

Additional dotfiles repositories (e.g. work-specific configurations) can be
integrated using the =--overlay-dir= option. An overlay directory is stowed on
top of the personal dotfiles and its =configure= script is executed
automatically if present.

#+begin_src shell
./configure -i --overlay-dir ../dotfiles-work
#+end_src

Multiple overlays can be specified:

#+begin_src shell
./configure -i --overlay-dir ../dotfiles-work --overlay-dir ../dotfiles-other
#+end_src

An overlay repository should follow the same directory structure as this
repository (stow-compatible, mirroring =$HOME=). Place a =.stow-local-ignore=
file and an executable =configure= script at its root for any overlay-specific
setup steps.
