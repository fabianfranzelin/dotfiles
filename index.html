System Configuration

In this repository, I gather my system configurations that allow me to have a consistent computing experience over multiple Linux machines.

It configures three main tools: GNU Emacs, ZSH, and Qtile.

I use GNU Stow to install my configuration files on my Linux distributions. Everything can be rolled out by calling the main configure script of the repository 

./configure -i
