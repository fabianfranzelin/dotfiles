* Installation instructions

Currently, I use version 28 of Emacs. Since it is not officially
released yet, I have to build it myself.

To do so, you need to install quite some third-party packages

#+begin_src shell
  sudo apt install libxpm-dev libgif-dev libjpeg-dev libpng-dev libtiff-dev libx11-dev libncurses5-dev automake autoconf texinfo libgtk2.0-dev libgtk-3-dev gcc-10 g++-10 libgccjit0 libgccjit-10-dev libgccjit-9-dev libjansson4 libjansson-dev libgnutls28-dev libacl1-dev libmagickwand-dev
#+end_src

Then, clone the Emacs repository and checkout the current release branch of version 28

  #+begin_src shell
    mkdir -p "${HOME}/opt"
    cd "${HOME}/opt"
    git clone https://git.savannah.gnu.org/git/emacs.git emacs-28.0
    cd "emacs-28.0"
    git checkout emacs-28
  #+end_src

To build Emacs, run

#+begin_src shell
  export CC=/usr/bin/gcc-10 CXX=/usr/bin/gcc-10
  ./autogen.sh
  ./configure --with-modules --with-gnutls --with-rsvg --with-x --with-json --prefix $HOME/opt/emacs-28.0 --bindir $HOME/opt/emacs-28.0/bin CFLAGS="-O3 -mtune=native -march=native -fomit-frame-pointer" --with-mailutils --with-native-compilation --with-imagemagick --with-jpeg --with-png --with-rsvg --with-tiff --with-wide-int --with-xft --with-xml2 --with-xpm
  make -j${nproc} && make install
#+end_src

Finally, make the new version globally available in your system using
update-alternatives.

#+begin_src shell
  sudo update-alternatives --install /usr/bin/emacsclient emacsclient $HOME/opt/emacs-28.0/bin/emacsclient 4
  sudo update-alternatives --install /usr/bin/emacs emacs $HOME/opt/emacs-28.0/bin/emacs 4
  sudo update-alternatives --config emacs
  sudo update-alternatives --config emacsclient
#+end_src

Once you have Emacs installed, it configures it on its own at
startup. Make sure that you ran

#+begin_src shell
  ./configure
#+end_src

before you do so.
