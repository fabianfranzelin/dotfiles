There is a minimal example available online to test the setup: Typescript Emacs project (remote)

  1. Clone the repository first
git clone "https://github.com/cpbotha/typescript-emacs-demo.git" "~/workspace"
cd "~/workspace/typescript-emacs-demo/"

Then install all the npm dependencies before you start the development server 

npm install
yarn start
