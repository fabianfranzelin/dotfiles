Simple C++/CMake Project

This is a minimal C++ project using CMake and Bazel to test Emacs configuration for C++ development (eglot, clangd, compilation).

Files

  • MODULE.bazel - Bazel module definition
  • BUILD - Bazel build file
  • compile_commands.json - Compilation database for clangd
