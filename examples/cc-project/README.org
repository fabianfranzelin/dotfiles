#+TITLE: Simple C++/CMake Project

This is a minimal C++ project using CMake and Bazel to test Emacs
configuration for C++ development (eglot, clangd, compilation).

** Source Code

Browse the full source on GitHub:
[[https://github.com/fabianfranzelin/dotfiles/tree/nightly/examples/cc-project][cc-project on GitHub]]

** Files

- =main.cpp= - Entry point
- =CMakeLists.txt= - CMake build configuration
- =MODULE.bazel= - Bazel module definition
- =BUILD= - Bazel build file
- =compile_commands.json= - Compilation database for clangd

** Debugging

*** Emacs (dape)

A =dape-command= is configured in =.dir-locals.el= using GDB's native
DAP mode. Run =M-x dape RET RET= to build with debug symbols and
launch the debugger.

*** VSCode

The =.vscode/launch.json= and =.vscode/tasks.json= dynamically query
Bazel for all =cc_binary= targets and present them in a picker before
building and debugging.
