Example Projects to Test Emacs Configuration

This folder contains some code examples to test my system configuration.

Internal examples

  • Scientific paper with org-mode
  • Simple C++/CMake project
  • Simple Python project
  • TypeScript project (tree-sitter + eglot)

External: Typescript and React

There is a more complete example available online to test the setup: Typescript Emacs project (remote)

  1. Clone the repository first
git clone "https://github.com/cpbotha/typescript-emacs-demo.git" "~/workspace"
cd "~/workspace/typescript-emacs-demo/"

Then install all the npm dependencies before you start the development server 

npm install
yarn start
