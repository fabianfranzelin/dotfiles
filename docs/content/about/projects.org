- *Outcome:* Unified data pipeline enabling efficient resimulation and

- *Context:* Digital test platform requiring elastic compute and storage

- *Role:* Software architect for test automation; designed heterogeneous

- *Technologies:* Python, Kubernetes, Docker, Airflow

- *Context:* Safety-critical validation environment for SAE Level 3–4

- *Role:* Software developer building cloud-based open-loop test

- *Technologies:* Python, Airflow, Kubernetes, Docker
- *Outcome:* Production test infrastructure enabling continuous

** PhD Research — Uncertainty Quantification for Subsurface Flows

- *Context:* Stochastic analysis of error propagation in
  high-dimensional simulations to identify optimal nuclear waste
  repository sites
- *Role:* Researcher developing data-driven methods for uncertainty
  quantification in large-scale numerical systems
- *Technologies:* Python, C++, HPC clusters
- *Outcome:* Novel methodology published as doctoral thesis (Summa Cum
  Laude), contributing to the SimTech Cluster of Excellence
