Vcxsrv

  • XLaunch setup for vcxsrv
  • Configure X server

    I found the best way to use the vcxsrv is to use the multi-window mode. Each GUI starts in its own window, it can be resized on-the-fly and they do not interfere with one another in the same window. Use the following command to start vcxsrv in that mode 

    "C:\Program Files\VcXsrv\vcxsrv.exe" :0 -clipboard -ac -multiwindow -wgl
    • :0 Display number
    • clipboard Enable clipboard sharing between host and wsl
    • ac Disable access control restrictions so that the wsl client can connect to the server
    • wgl Enable GLX extension

    For details, check the command line options of vcxsrv.
